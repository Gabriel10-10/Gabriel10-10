### IoT Real-Time Data Pipeline

Built an end-to-end Azure streaming pipeline ingesting telemetry from multiple concurrent IoT sensors through Azure IoT Hub.

Processed streaming data using Azure Stream Analytics with 5-minute tumbling windows, persisted data in Cosmos DB and Blob Storage, and developed a Node.js dashboard for real-time monitoring.

**Technologies:** Azure IoT Hub, Stream Analytics, Cosmos DB, Blob Storage, Node.js

[View Project](https://github.com/Gabriel10-10/iot-realtime-monitoring-platform)

### Enterprise AI RAG System

Contributed to an industry-sponsored, multi-tenant Retrieval-Augmented Generation (RAG) application integrating enterprise knowledge with large language models.

Worked on components involving data retrieval, cloud services, and an evaluation system for assessing AI-generated responses.

**Technologies:** Python, Azure, Cosmos DB, PostgreSQL, RAG, LLMs

### Cloud DevOps Pipeline : Weather App

Designed and implemented an automated CI/CD pipeline for a containerized application deployed on Azure Kubernetes Service.

Used Terraform for infrastructure provisioning and GitHub Actions for automated testing, security scanning, and deployment across test and production environments.

**Technologies:** Azure, Terraform, Kubernetes, Docker, GitHub Actions

### Serverless Workflow Orchestration on Azure

Compared both approaches in terms of reliability, cost, and developer experience.
